# Voz de la Novia

Cancionero del Tabernáculo Shalom Adonai: canciones por tono, programas de cánticos, modo en vivo y PDF de letra o letra con acordes.

Variables necesarias en Railway:
- `DATABASE_URL` — conexión a Postgres
- `EDITOR_PASSWORD` — contraseña del director para editar
- `TOKEN_SECRET` — texto aleatorio para firmar la sesión
